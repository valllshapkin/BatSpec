
# 🧠 База знаний: Архитектура и кастомизация ROI в pyqtgraph

Класс `pyqtgraph.ROI` (наследуется от `GraphicsObject` -> `QGraphicsObject`) представляет собой интерактивную область на графике (обычно поверх изображений), которую пользователь может перемещать, масштабировать и вращать.

## 1. Внутреннее устройство и Состояние (State)
Вместо прямого хранения геометрии в координатах сцены, ROI хранит свое состояние в словаре `self.state`:
*   `pos` (Point): Позиция начала координат ROI (обычно нижний левый угол bounding box).
*   `size` (Point): Ширина и высота ROI.
*   `angle` (float): Угол поворота в градусах.

**Важно:** Никогда не меняйте `self.state` напрямую! Используйте методы `setPos()`, `setSize()`, `setAngle()` или `setState()`. Они автоматически обновляют трансформации, двигают ручки (Handles) и вызывают сигналы (emits).

## 2. Ручки управления (Handles)
Интерактивность достигается за счет прикрепления объектов класса `Handle`. Координаты ручек задаются в **относительных координатах [0.0 - 1.0]**, где `[0, 0]` — это начало координат ROI, а `[1, 1]` — противоположный угол, независимо от текущего размера.

### Типы ручек (методы для их добавления):
*   `addTranslateHandle(pos)`: Перемещает весь ROI целиком.
*   `addScaleHandle(pos, center)`: Масштабирует ROI. `center` — неподвижная точка, относительно которой идет масштабирование. Если координата X или Y у `pos` и `center` совпадают, масштабирование по этой оси блокируется.
*   `addRotateHandle(pos, center)`: Вращает ROI вокруг точки `center`.
*   `addScaleRotateHandle(pos, center)`: Одновременный скейл (отдаляя/приближая к центру) и вращение.
*   `addFreeHandle(pos)`: Свободная ручка (не влияет на размер/угол ROI). Полезна для `PolyLineROI`.
*   `addRotateFreeHandle(pos, center)`: Вращает ROI, но изменение дистанции от центра игнорируется.

## 3. Как наследоваться и создавать свой ROI

Чтобы создать кастомную фигуру, нужно наследоваться от `ROI` и переопределить несколько ключевых методов.

### Шаблон кастомного ROI:
```python
import pyqtgraph as pg
from pyqtgraph.Qt import QtCore, QtGui

class CustomROI(pg.ROI):
    def __init__(self, pos, size, **kwargs):
        # 1. Инициализация базового класса
        super().__init__(pos, size, **kwargs)
        
        # 2. Добавление ручек управления
        self.addScaleHandle([1, 1], [0, 0])
        self.addRotateHandle([1, 0], [0.5, 0.5])
        
        # 3. Кеш для QPainterPath (если нужно)
        self.path = None

    def paint(self, p, opt, widget):
        # Отрисовка фигуры
        # ВАЖНО: Рисовать нужно в локальной системе координат ROI
        p.setRenderHint(QtGui.QPainter.RenderHint.Antialiasing, self._antialias)
        p.setPen(self.currentPen)
        
        # Координаты нормализованы или требуют масштабирования под self.state['size']
        r = self.boundingRect()
        p.scale(r.width(), r.height())
        p.drawRect(QtCore.QRectF(0, 0, 1, 1)) # Пример: рисуем квадрат

    def shape(self):
        # Точная форма фигуры для определения кликов мышью и масок пересечения.
        # Возвращает QPainterPath
        if self.path is None:
            self.path = QtGui.QPainterPath()
            self.path.addRect(self.boundingRect())
        return self.path

    def boundingRect(self):
        # Ограничивающий прямоугольник без учета вращения
        return QtCore.QRectF(0, 0, self.state['size'][0], self.state['size'][1]).normalized()

    def getArrayRegion(self, data, img, axes=(0,1), **kwds):
        # Опционально: переопределить, если фигура не прямоугольная 
        # (см. раздел "Извлечение данных" ниже)
        return super().getArrayRegion(data, img, axes, **kwds)
```

## 4. Что и зачем переопределять (Справочник методов)

*   `__init__`: Обязательно вызывать `super().__init__` и расставить нужные Handles.
*   `paint(p, opt, widget)`: Отрисовка. Обратите внимание, что `p.setPen(self.currentPen)` гарантирует, что ROI будет менять цвет при наведении мыши (Hover effect).
*   `shape()`: Обязательно переопределить для непрямоугольных фигур (Круг, Треугольник, Линия). Qt использует метод `shape()`, чтобы понять, попал ли клик мышкой в ROI. Возвращает `QPainterPath`.
*   `boundingRect()`: Должен возвращать `QRectF`, охватывающий фигуру при нулевом угле поворота. Базовая реализация `ROI` возвращает прямоугольник `(0, 0, width, height)`. Переопределяйте, если ваш ROI рисуется вне этих границ (например, линия от центра).
*   `getArrayRegion()`: Переопределяется, чтобы правильно вырезать данные из массива NumPy, соответствующего картинке под ROI.

## 5. Извлечение данных (Data Extraction)
Самая мощная фича ROI — способность вырезать пиксели из `ImageItem` под собой.

*   **Для прямоугольников:** Используется базовый `ROI.getArrayRegion()`, который применяет афинные преобразования (`affineSlice`).
*   **Для произвольных фигур (Треугольники, Эллипсы, Многоугольники):** Базовый метод захватит прямоугольный bounding box. Чтобы обрезать лишнее нулями, в `pyqtgraph` встроен помощник: `self._getArrayRegionForArbitraryShape(...)`.
    *   *Как это работает:* Метод рисует `self.shape()` в QImage (создает бинарную маску), переводит ее в NumPy array и умножает полученный квадратный срез данных на эту маску.
    *   *Требование:* Для этого ваш `shape()` должен возвращать математически точный `QPainterPath` вашей фигуры с учетом `size`.

*Пример использования для сложной фигуры (из TriangleROI):*
```python
def getArrayRegion(self, *args, **kwds):
    return self._getArrayRegionForArbitraryShape(*args, **kwds)
```

## 6. Сигналы (Signals)
При разработке UI интерфейсов на эти сигналы нужно подписываться:
*   `sigRegionChangeStarted`: Пользователь зажал мышь на ROI или его ручке.
*   `sigRegionChanged`: Вызывается постоянно **во время** перетаскивания (для live-апдейтов).
*   `sigRegionChangeFinished`: Пользователь отпустил мышь. (Обычно тяжелые расчеты вешают именно сюда).
*   `sigHoverEvent`: Мышь над ROI.
*   `sigClicked`: Клик по ROI (Внимание: по умолчанию клики отключены, чтобы не перехватывать их у картинки сзади. Включается через `self.setAcceptedMouseButtons(QtCore.Qt.MouseButton.LeftButton)`).
*   `sigRemoveRequested`: Запрос на удаление (через контекстное меню).

## 7. Связанные классы (Вспомогательные)
*   **`Handle`**: Класс самих точек-ручек. Отвечает за свою отрисовку (квадрат/круг/алмаз в зависимости от типа), обрабатывает драг-н-дроп мышью и шлет вызовы `roi.movePoint(...)` своему родительскому ROI.
*   **`MouseDragHandler`**: Отдельный класс-делегат, встроенный в `ROI`. Обрабатывает драг-н-дроп **самого тела ROI** (не ручек!). Реализует логику:
    *   ЛКМ + Drag = Перемещение
    *   ЛКМ + Alt + Drag = Вращение
    *   ЛКМ + Shift + Drag = Масштабирование
    *   ЛКМ + Ctrl + Drag = Прилипание к сетке (Snap)

## 8. Существующие (встроенные) ROI-классы для примера
Если вам нужно сделать что-то похожее, изучите исходники этих классов:
*   `RectROI` — прямоугольник с базовыми масштабаторами.
*   `EllipseROI` / `CircleROI` — эллипс/круг. Переопределен `getArrayRegion` для математической маски круга (без `_getArrayRegionForArbitraryShape`).
*   `LineROI` — прямоугольник, но управляемый ручками по краям "линии" посередине.
*   `LineSegmentROI` — простая линия (вектор) между двумя независимыми ручками. Возвращает 1D-массив данных.
*   `PolyLineROI` — ломаная линия. Состоит из множества вложенных `_PolyLineSegment` (которые являются `LineSegmentROI`).
*   `TriangleROI` — равносторонний треугольник. Отличный пример того, как использовать кастомный `QPainterPath` (полигон).
